OpenPiton SRAM Macro Timing Views
=================================

This directory contains OpenPiton SRAM hard-macro collateral used by the
sample OpenPiton physical-design flows.

- `2d_hard_lib/`: Liberty timing/power views for the OpenPiton SRAM macros.

The OpenPiton macro LEF files are included with the sample design folders under
`Sample Designs/PnR Sample-*/openpiton/HARD-LEF (OpenPiton)/`.
