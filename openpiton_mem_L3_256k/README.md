OpenPiton SRAM Macro Timing Views
=================================

This directory contains shared OpenPiton SRAM hard-macro collateral used by
the sample OpenPiton physical-design flows.

- `2d_hard_lef/`: LEF physical views for the OpenPiton SRAM macros.
- `2d_hard_lib/`: Liberty timing/power views for the OpenPiton SRAM macros.
